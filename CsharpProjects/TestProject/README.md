# Demo MVC en .NET

Este proyecto es una aplicación ejecutable de consola que muestra una estructura MVC básica:

- Models: representa los datos.
- Views: controla la presentación visual en consola.
- Controllers: maneja la lógica y la interacción.
- Data: simula el almacenamiento backend.

## Ejecutar

```bash
dotnet run
```

## Estructura

```text
TestProject/
├── Controllers/
├── Data/
├── Models/
├── Views/
├── Program.cs
├── TestProject.csproj
└── README.md
```

## Objetivo

Es una demo simple para entender cómo se organiza una aplicación .NET ejecutable y cómo se separan las capas de front y back.
